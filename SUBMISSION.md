# Lab 06 Submission

- **Platform:** Swift / SwiftUI
- **Repository:** `https://github.com/akkubais/hw_lab_akkubais`
- **Branch:** `hw_lab6_SimpleContacts`

## Completed functionality

- SwiftData `Person` model and persistent model container
- Add and edit contacts
- Name and email fields with appropriate text content types
- Details field
- Search by contact name
- Sort by name A-Z or Z-A
- Swipe-to-delete
- Photo selection with `PhotosPicker`
- Five Swift Testing tests covering defaults, insertion, deletion, sorting, and search

## Verification

The app builds successfully for the iOS Simulator. All five automated tests pass on an iPhone 17 Pro simulator.

The `Screenshots` folder contains the main list, descending sort, filtered search, and contact detail/photo screens.
