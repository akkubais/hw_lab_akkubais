# Screenshots to capture before submitting

No app screenshots have been captured during preparation: iOS Simulator access was unavailable in the preparation environment. These instructions are not screenshots.

Run RailsCards in an iPhone simulator and save these images:

1. **01-command.png**: command screen with a readable Rails command.
2. **02-definition.png**: tap that exact card and capture its matching definition with the navigation back button visible.
3. **03-new-command.png**: go back; capture a different randomly drawn command. If the same command is drawn, reveal it and go back again.
4. **04-tests-passed.png**: recommended additional evidence showing the five required Swift Testing tests passing in Xcode after Command-U. A test screenshot does not replace the app screenshots.

For simulator images, use the Simulator's screenshot/save-screen command (Command-S), then place the saved images in this folder and attach them to Canvas. Use your Mac's screenshot tool for Xcode test results.

Alternatively, the included UI test saves the three app screenshots as retained attachments. After Command-U succeeds, open the test report in Xcode's Report navigator, locate `testRevealDefinitionAndDrawOnReturn`, and export its `01-command`, `02-definition`, and `03-new-command` image attachments.

Capture real running app screens. Do not submit the handout's example images or this README as output screenshots.
