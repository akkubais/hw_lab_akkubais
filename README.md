# Lab 04 SimpleBrowser

Platform: Swift using SwiftUI and WebKit.

## Features

- Enter a URL and open it in an embedded `WKWebView`.
- Navigate back and forward through browsing history.
- Reload or stop the current page.
- Open the iOS share sheet for the current page.
- Normalize addresses without a scheme by adding `https://`.

## Run

1. Open `SimpleBrowser.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Press Run.
4. Type a URL such as `example.com` and press Go.

Screenshots of the significant outputs are included in the `Screenshots` folder.
