# BookManager - SwiftUI

BookManager is the Swift version of Lab 03. It demonstrates tab navigation, shared state, forms, list navigation, swipe-to-delete, and Swift Charts.

## Features

- Library tab with 78 seeded classic books sorted by title
- Book detail screen showing title, author, gender, and display status
- Swipe-to-delete and Edit mode
- New Book form with validation, gender picker, display toggle, and success confirmation
- Charts for author gender and five selected authors

## Run

1. Open `BookManager.xcodeproj` in Xcode.
2. Select any iPhone simulator.
3. Run the `BookManager` scheme.

## Platform

Swift / SwiftUI, iOS 17 or later.
