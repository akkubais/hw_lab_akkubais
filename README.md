# Lab 06: SimpleContacts

Platform: **Swift (SwiftUI)**

SimpleContacts is an iOS contact manager built with SwiftUI and SwiftData. It supports persisted contacts, editing, search, ascending/descending name sorting, swipe-to-delete, and contact photos selected from the photo library.

## Requirements

- Xcode 27 or later
- iOS 18 or later

## Run

1. Open `SimpleContacts.xcodeproj`.
2. Choose an iPhone simulator.
3. Run the `SimpleContacts` scheme.

## Tests

Run the test suite with **Product > Test** (`Cmd-U`). The Swift Testing suite covers model defaults, SwiftData insertion, deletion, sorting, and searching.
