# Lab 02 submission checklist

Platform used: **Swift (SwiftUI)**.

Repository: https://github.com/akkubais/hw_lab_akkubais

Required branch: **hw_lab2_RailsCards**.

Branch link to submit: https://github.com/akkubais/hw_lab_akkubais/tree/hw_lab2_RailsCards

## Before submitting

- [ ] Open `RailsCards.xcodeproj`, select the RailsCards scheme and an iPhone simulator, and run the app with Command-R.
- [ ] Verify: tap a command to show its definition, then go back to draw another random card. Both faces should show the rounded 350 x 200 card.
- [ ] Run Command-U and verify the five required Swift Testing tests pass in Xcode. The additional UI test should also pass and generate three screenshot attachments.
- [ ] Save the command screen, its matching definition screen, and another command after returning. See `Screenshots/README.md` for exact capture instructions. Also save Xcode's passing test results as recommended evidence.
- [ ] Confirm the branch on GitHub contains all RailsCards source files, the Xcode project, and tests.
- [ ] If you add screenshots to the repository, commit and push those files to `hw_lab2_RailsCards` through your own GitHub account. Attaching them directly to Canvas is the explicit screenshot requirement.
- [ ] Confirm your assigned CA has repository access. The existing repository already grants collaborator access to GitHub user **a-belard**. If this is your assigned CA, no additional invitation is needed. Otherwise invite the correct CA under repository Settings > Collaborators, and confirm access.

## What Canvas requires

1. A note clearly identifying **Swift** as the chosen platform.
2. **Screenshots showing all significant outputs**: the command, its matching definition, and a new random command after going back demonstrate the app's significant behavior. Passing-test evidence is recommended because the handout requires running the tests.
3. A **GitHub repository link**. Include the branch link too, so the CA reaches Lab 2 directly.

The instructions provided do not require completing both Swift and React Native, uploading a source-code ZIP to Canvas, submitting a video, or taking separate screenshots of all 22 cards.
